# Gyanig Kumar - Portfolio Website

Personal portfolio website showcasing research in Human-Robot Interaction (HRI), Computer Vision, and autonomous systems.

## Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System)
- **Animations**: GSAP (GreenSock Animation Platform)
- **Icons**: Phosphor Icons
- **Deployment**: GitHub Pages (gyanigk.github.io)

## Repository Structure

- `assets/`: Centralized storage for all static assets
  - `css/`: Custom stylesheets
  - `images/`: Project screenshots, profile photos, and UI assets
  - `data/`: PDF papers, reports, and presentation slides
  - `media/`: Video compositions and performance recordings
  - `js/`: Application logic and GSAP animations
- `projects/`: Deep-dive technical pages for specific works
- `index.html`: Main landing page and bio
- `projects.html`: Interactive projects bento grid
- `hobbies.html`: Photography and music portfolio
- `logs.html`: Weekly research and failure logs

## Local Development

Run `python scripts/serve.py` and open http://localhost:8766. No build step is required.
The preview serves the repository directly and disables browser caching so edits
appear consistently across pages. Use the same hostname and port when navigating
to keep your saved light/dark preference. Stop the server with Ctrl+C.
